# Sistema-de-Inferencia-Borrosa-para-la-Estimaci-n-del-Desempe-o-Acad-mico-Universitario
Sistema de Inferencia Borrosa para la Estimación del Desempeño Académico Universitario
El sistema utiliza lógica difusa para estimar el desempeño académico de estudiantes universitarios considerando variables como asistencia, horas de estudio y nivel de estrés.
Tecnologías utilizadas
- Python
- scikit-fuzzy
- Streamlit
- NumPy
- Plotly
 Variables de entrada
- Asistencia a clases
- Horas de estudio
- Nivel de estrés académico
 Variable de salida
- Desempeño académico estimado
